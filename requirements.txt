DEPENDENCIAS PRINCIPALES
------------------------
- libpysal, geopandas, esda, spreg
- matplotlib, seaborn, plotly
- gradio
- pandas, numpy, scipy, statsmodels, scikit-learn

FUENTES DE DATOS OFICIALES RECOMENDADAS
---------------------------------------
- Deforestación / pérdida de bosque: IDEAM SMByC, Global Forest Watch, MapBiomas Colombia
- Valor Agregado Agrícola: DANE – Cuentas Nacionales Departamentales (rama Agricultura, ganadería, caza, silvicultura y pesca)
- Densidad / longitud de red vial: INVIAS + DNP
- Proxy satelital: VIIRS nighttime lights (WorldPop / EOG) o alertas FIRMS agregadas a nivel departamental
- GeoJSON departamentos: https://raw.githubusercontent.com/caticoa3/colombia_mapa/master/co_2018_MGN_DPTO_POLITICO.geojson

NOTAS IMPORTANTES
-----------------
- El panel de datos incluido es de referencia (orden de magnitud real). 
  Debe reemplazarse por series oficiales completas para análisis de producción.
- El modelo implementa selección empírica de estructura espacial (SAR / SEM / SAC-SDM) 
  mediante pruebas de Multiplicadores de Lagrange.
- Se calculan efectos directos e indirectos (spillovers espaciales).
- Incluye mapas coropléticos, visualización 3D interactiva y aplicación Gradio.

ESTRUCTURA DEL SCRIPT
---------------------
1. Instalación de dependencias
2. Carga del GeoJSON oficial de departamentos de Colombia
3. Construcción / carga del panel espacio-temporal
4. Construcción y selección de la matriz de pesos espaciales W (Queen vs Rook)
5. Preparación de datos para el sistema SpVAR
6. Selección empírica de modelo espacial por ecuación (LM tests)
7. Cálculo de impactos directos, indirectos y totales
8. Generación de mapas coropléticos y gráfico 3D
9. Auditoría interna de robustez
10. Lanzamiento de la aplicación interactiva Gradio
